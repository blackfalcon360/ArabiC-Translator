# Arabic Translator

انگریزی اور اردو کو فصیح عربی اور تمام عرب لہجوں میں ترجمہ کرتی ہے، ہر نتیجے کے ساتھ ملک کا جھنڈا اور نام۔ اور الٹا بھی: عربی (کسی بھی لہجے) سے انگریزی/اردو/فصیح میں، اور انگریزی ↔ اردو۔

## ایپ کیا کرتی ہے
- ترجمہ ٹیب: "کس زبان سے" (خودکار / English / اردو / العربية) اور "کس میں" (انگریزی، اردو، فصیح عربی، اور لہجے)۔ ایک ساتھ کئی زبانوں/لہجوں میں ترجمہ، ہر کارڈ پر کاپی اور شیئر۔ "سب نتائج کاپی کریں" بھی ہے۔
- لہجے ٹیب: 22 عرب ممالک (جھنڈے، ملک کے نام اور لہجے کے ساتھ)، علاقے کے لحاظ سے: وادیٔ نیل (مصر، سوڈان)، بلاد الشام (شام، لبنان، فلسطین، اردن)، جزیرہ نما عرب، عراق اور یمن (سعودی، امارات، کویت، قطر، بحرین، عمان، عراق، یمن)، مغرب (مراکش، الجزائر، تیونس، لیبیا، موریطانیہ)، اور صومالیہ، جبوتی، کومورو۔
- زبان خودکار پہچانی جاتی ہے (اردو اور عربی کے حروف سے)؛ غلط پہچان ہو تو "کس زبان سے" خود چنیں۔
- UI کی زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## دو انجن
- بغیر کی (مفت): صرف انگریزی، اردو اور فصیح عربی کے درمیان، مفت سروس MyMemory سے۔ روزانہ حد ہے اور معیار اوسط ہو سکتا ہے۔
- Claude API کی کے ساتھ (سیٹنگز میں): ہر زبان اور تمام لہجے، اور لہجے سے دوسری زبانوں میں بھی۔ ماڈل ڈیفالٹ `claude-haiku-5-5`، سیٹنگز میں بدلا جا سکتا ہے۔ فیس آپ کی کی پر لگتی ہے۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `ArabicTranslator-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں؛ صرف INTERNET پرمیشن۔ ترجمے کے لیے انٹرنیٹ لازمی ہے۔
- لہجوں کے ترجمے کے لیے مفت آف لائن یا بغیر کی سروس موجود نہیں، اس لیے Claude کی ضروری ہے۔
- یہ مشین ترجمہ ہے؛ لہجوں کا نتیجہ اندازاً ہوتا ہے۔ اہم، مذہبی یا قانونی متن کسی ماہر سے جانچ لیں۔
- صومالیہ، جبوتی اور کومورو میں عربی کے الگ نمایاں لہجے کم ہیں۔
- ترجمہ کا متن MyMemory یا Anthropic کے سرور کو جاتا ہے؛ کی صرف آپ کے فون میں رہتی ہے۔
